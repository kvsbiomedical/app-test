# DermaScan AI Demo

A polished single-page skin cancer screening demo app with:

- Live camera feed support (`getUserMedia`)
- Frame capture from the camera
- Image file upload fallback
- Auto-generated detailed screening report (ABCDE, pattern notes, next steps)
- Visual risk meter and risk badge

## Run locally

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000` in your browser.

> Disclaimer: this project is an educational front-end prototype and does not provide medical diagnosis.
